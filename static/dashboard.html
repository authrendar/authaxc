Manage Apps API Docs (Seller Integration)

Seller API Documentation

Integrate key generation and user creation directly into your custom website, shop, or Discord bot.

Seller API Documentation (Automated Key & User Generation)

1. Generate License Keys via External Website / Bot

Send an HTTP POST request from your website backend, Discord bot, or payment gateway (Sellix / WooCommerce / Shoppy) to automatically issue keys using your App Secret Key.

POST http://127.0.0.1:8000/api/seller/generate

// Request Body (JSON):
{
  "app_id": "YOUR_APP_ID",
  "seller_key": "YOUR_APP_SECRET", // Found in Manage Apps (Application Secret)
  "duration_days": 30, // 0 for Lifetime
  "count": 1,
  "note": "Automated Web Purchase"
}

2. Create User Account directly via API

Allow your web users to create an account directly from your custom website form.

POST http://127.0.0.1:8000/api/seller/user/create

// Request Body (JSON):
{
  "app_id": "YOUR_APP_ID",
  "seller_key": "YOUR_APP_SECRET", // Found in Manage Apps (Application Secret)
  "username": "customer_user",
  "password": "customer_pass",
  "duration_days": 30
}
